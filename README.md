# Технадзор автодорог РК — панель контроля КАЖ

Веб-приложение для цифрового технического надзора на автодорогах Казахстана —
не только платных, но и республиканских / местных, по всем 16 областям.
Инженеры технадзора вносят данные прямо на объекте (приёмка этапов, акты скрытых
работ, дефекты, объёмы работ к оплате), а КАЖ видит все решения технадзора на
единой панели, может их подтверждать или оспаривать, следить за статистикой по
дорогам и подрядчикам — то есть осуществляет **надзор над технадзором**.

## Выбор дороги

Форма технадзора использует каскадный выбор:

1. **Область** — все регионы РК.
2. **Тип ремонта** (необязательно) — строительство и реконструкция /
   реконструкция / капитальный ремонт / средний ремонт — сужает список дорог.
3. **Дорога / участок** — реестр из 230+ реальных участков, взятый из отчёта
   по дефектам и гарантийным периодам.

Километраж указывается вручную (участки внутри одной дороги часто отличаются).
Если нужной области, типа ремонта, дороги или вида работ нет в списке — в любом
из этих полей можно выбрать **«+ Добавить свой вариант»** и вписать значение
вручную (реестр не покрывает 100% случаев, особенно локальные дороги).

## Модель данных

Четыре типа записей, единый журнал:

- **Приёмка этапа** — подтверждение, что выполненный этап работ соответствует
  проекту (заключение «соответствует» / «не соответствует», объём план/факт).
- **Акт скрытых работ** — фиксация состояния работ, которые нельзя будет
  проверить визуально после того, как их закроет следующий слой (например,
  основание дороги перед укладкой асфальта).
- **Дефект** — выявленное нарушение с требованием устранения в срок,
  фотофиксацией "было/стало" и уведомлением подрядчика по email.
- **Объём работ** — объём, предъявляемый подрядчиком к оплате (кол-во × цена).

Каждая запись содержит: дорогу, километраж/участок, подрядчика, инженера
технадзора, геолокацию, фото с камеры и **статус надзора КАЖ**
(не проверено / подтверждено / оспорено).

## Роли

- **Технадзор** (инженер на объекте) — вносит записи через форму «Форма
  технадзора». Замена бумажных актов и журналов работ.
- **КАЖ** — просматривает панель, подтверждает или оспаривает решения
  технадзора, видит сводку по дорогам и подрядчикам (открытые дефекты,
  несоответствия, оспоренные решения, суммы к оплате).
